# DISCIPLINE — Phase 1

A responsive local frontend prototype for the DISCIPLINE journey management application.

## What's included
- Premium navy, black and gold interface
- Responsive sidebar and mobile navigation
- Administrator command-center dashboard
- Weekly overview and illustrative chart
- Navigation previews for all planned modules
- Demonstration modal forms for adding a student, awarding marks and recording an incident

## Run locally
1. Extract the `DISCIPLINE` folder.
2. Open `index.html` in a modern web browser.
3. For best results, use a local static server (for example, VS Code Live Server).

No installation or build step is required.

## Important limitations
This is Phase 1: frontend and navigation prototype only.
- All dashboard figures and names are fictional demonstration data.
- Forms are demonstrations and do not save records.
- No Supabase project is connected.
- No real authentication, database, audio recording, transcription, parent access or student access is implemented yet.
- Do not enter real student or parent information in this prototype.

## Next phase
Approve the interface, then configure a Supabase project and implement authentication, PostgreSQL tables, Row Level Security, and real student/parent relationships before entering any real records.
